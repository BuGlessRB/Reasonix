> 这一版有一件新能力和一件旧账。新能力是 **DeepSeek 能看图了**——升级完什么都不用改，模型自己会出现在列表里。旧账是长会话：每一轮都在为模型根本看不到的历史付钱，二十万条消息的会话一轮要白扔 14MB。另外，补全菜单、模型列表、右栏报错这三处「当前是哪一个」终于看得清了。

## ⚠️ Windows 用户先看这一条

如果你现在装的是 **2.2.0 或更早**，这一次要**手动下载安装包覆盖安装**，自动更新会失败。

Studio 装在 `Program Files` 并写 HKLM，安装包因此声明了需要管理员权限，而旧版用来启动它的那个调用**从来起不动这种程序**——下载好、校验完，然后卡在最后一步。修复在这一版里，所以它只对**从这一版往后**的升级生效。装上 2.3.0 之后，以后的自动更新会正常弹 UAC。

macOS 和 Linux 不受影响。

## DeepSeek 能看图了

- **`deepseek-v4-flash-vision-exp` 现在可以直接用**。DeepSeek 新上了这个实验性的视觉模型，Studio 之前把整个 DeepSeek 端点当作「只收文本」——那是当时的事实，现在不是了。判断从「这个端点」改成了「这个模型」：同一个连接里，视觉模型的「读图」可以勾，另外两个仍然不能（端点自己会拒）。
- **升级即到位，不用改配置**。已经装好的用户，模型列表是冻在配置文件里的，不会自己长出新模型。这一版会在启动时补上——但只补那些**还是我们出厂原样**的连接；你自己策展过的列表一律不碰。
- **它不只是能看图**：实测工具调用和思考档位都支持，所以可以直接当主模型用，不是只能当「看图」角色。
- **主模型看不了图的时候，提示不再骗人**。以前无论如何都说「改由委派的子代理去看」，可要是你没指定「看图」角色，图片其实是在发出去之前就被丢掉的。现在它会点名说「`xxx` 能读图，去 设置 › 模型 › 分工 里指给它」，或者干脆说清楚「没有任何模型能读图」。
- 「看图」角色**不会自动帮你指定**——那等于替你决定把图片和账单送去一个你没挑过的实验模型。

## 长会话不再为看不见的历史买单

- **每一轮的开销不再跟着会话长度涨**。折叠（压缩）存在的全部意义就是让模型不必再看旧历史，但每一轮仍然会把整份记录复制一遍，只为了读末尾那几条：两万条消息的会话，一轮 2.3 毫秒、**14MB 垃圾**。现在是 0.45 毫秒、3.8KB，而且一百条和两万条一样快。
- 一轮请求的组装成本跟着降下来，从 2.3 毫秒到 3.3 微秒。
- 切项目时不再各自占一份系统提示前缀，多项目之间共用同一份缓存。

## 「当前是哪一个」看得清了

- **`/` 和 `@` 菜单里，键盘选中的那一行终于比鼠标划过的那一行显眼**。以前正好相反：选中只有一个 6 像素的点，而鼠标悬停是整行铺底色——鼠标停在列表上不动的时候，最亮的恰恰是回车不会选的那一行。现在键盘一接手就把悬停收掉，鼠标动了才交还。
- **模型列表能搜了，也能直接填**。中转站报出两百多个只差日期后缀的名字时，编辑面板过去一行一个全铺出来，整块四屏多高，保存按钮在屏幕外；勾中的那一个混在里面根本找不到。现在搜索和「填一个列表里没有的名字」是同一个框——列表里没有就直接用你打的这个名字。已勾选的排在最前面。
- **MCP 连不上时不再把右边的度量栏撑坏**。端点自己写的那句报错有多长不由我们定，它过去被塞进一个给「耗时」准备的槽里，结果服务名被挤成 0 像素、整栏横向溢出 451 像素，旁边每一块跟着错位。现在名字一行、原因一行（最多两行），连不上用左边一道红条标出来。

## 报错终于说得出「是哪一种错」

这一批改的是同一件事：**要分辨的错误带一个身份，而不是一句话**。靠匹配错误文本来判断「这是哪种失败」，换个语言、换个供应商就失灵。

- 流式响应中途断开，现在在断的地方就被命名，不再回头去猜那段文字是什么意思。
- 跨盘移动文件、启动步骤失败、插件迁移、会话停止——都改成读错误码或哨兵值。
- HTTP 那一侧，每一条拒绝都带上了点分码；前端说不出的码会让构建直接失败。
- 「这次改动没有任何东西验证过」现在会带上那条跑过、但没被当成检查的命令。
- 参数名写错时，就算错在数组里的某一项，也能说清是哪一层的哪个参数。

## 存储与迁移

- **换状态目录时，写在它下面的东西会一起走**。
- 迁移中途被打断（清单还没列完就开始搬），文件不会丢，会被找回来。
- 移动面板会说清楚哪些东西它没取到、留在了哪里，而不是安静地少几个。

## 其它

- 最大化那个图标现在跟着窗口的真实状态走，而不是跟着你刚点的那一下。
- 刚接上的订阅者不会被误判成「掉了一段没收到」。
- Studio 打包时 `hdiutil` 失败会说原因，不再只留一个退出码。
- 更新目录的地址由每条发布线自己声明，不再落到一个默认值上——那个默认值指向的地方什么都不发布。
